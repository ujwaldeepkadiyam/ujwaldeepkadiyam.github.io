<h2 class="page-header" style="text-align: center; color: blue;"><strong style="color: #cc33cc;">Git Foundations</strong></h2>

<h4 style="color: #cc33cc;">Course Introduction</h4>

<p style="text-align: justify;">
  A short course on how Git works under the hood — not just the commands, but the model behind them: commits as snapshots, branches as movable pointers, and HEAD as the thing that tracks where you currently are.
</p>

<h4 style="color: #cc33cc;">Course Materials</h4>

  * **Module 1: Introduction to Git Commits**
      * [Module 1: Introduction to Git Commits](/teaching/Developer%20Tools%20%26%20Workflows/Git-Foundations/modules/module-1-introduction-to-git-commits/) — what a commit is, why they're lightweight, and how `main` is just a movable label.


  * **Module 2: Git Branches**
      * [Module 2: Git Branches](/teaching/Developer%20Tools%20%26%20Workflows/Git-Foundations/modules/module-2-git-branches/) — creating and switching branches, working on them independently, merging, and how HEAD tracks your current branch.
