<h1 class="unnumbered" id="algebraic-structures-lecture-notes">Algebraic
Structures – Lecture Notes</h1>
<p>These are long-form lecture notes written in LaTeX, similar in spirit
to a single long Markdown document.</p>
<p>You can write normal text in paragraphs. Math works with inline
notation like <span class="math inline">\(a \in \mathbb{Z}_n\)</span>
and display math:</p>
<p><span class="math display">\[a + b \equiv c \pmod{n}.\]</span></p>
<h2 class="unnumbered" id="example-homomorphism-phi-mathbbz-to-mathbbz_n">Example: Homomorphism
<span class="math inline">\(\phi : \mathbb{Z} \to
\mathbb{Z}_n\)</span></h2>
<p>Define <span class="math display">\[\phi(a) = a \bmod n.\]</span></p>
<p>Then <span class="math display">\[\phi(a+b) = \phi(a) +
\phi(b)\]</span> so <span class="math inline">\(\phi\)</span> is a group
homomorphism from <span class="math inline">\((\mathbb{Z},+)\)</span> to
<span class="math inline">\((\mathbb{Z}_n,+)\)</span>.</p>
