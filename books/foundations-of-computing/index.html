Foundations of Computing

Core computing concepts with an emphasis on programming, algorithms, systems, and theoretical computer science.

Programming Fundamentals Data Structures and Algorithms Theory of Computation Computational Complexity Computer Systems Operating Systems Computer Networks Databases Software Engineering

Programming Fundamentals

The C Programming Language

Brian W. Kernighan and Dennis M. Ritchie

2nd edition, 1988

Commonly known as K&R, this classic introduces C through concise explanations and carefully designed examples. It remains an excellent foundation for systems programming, compilers, operating systems, and embedded software.

Recommended

Programming: Principles and Practice Using C++

Bjarne Stroustrup

2nd edition, 2014

Written by the creator of C++, this book teaches programming through problem solving, abstraction, object-oriented methods, generic programming, and software design. It prepares beginners for advanced software engineering and systems development.

Recommended

Introduction to Algorithms

Thomas H. Cormen, Charles E. Leiserson, Ronald L. Rivest, and Clifford Stein

4th edition, 2022

This comprehensive text builds disciplined algorithmic thinking through recursion, data representation, asymptotic analysis, and implementation techniques. In this section it serves as a bridge from introductory programming to formal algorithm design.

Recommended

Data Structures and Algorithms

Introduction to Algorithms

Thomas H. Cormen, Charles E. Leiserson, Ronald L. Rivest, and Clifford Stein

4th edition, 2022

A standard reference covering fundamental data structures, algorithm-design paradigms, graph algorithms, dynamic programming, greedy methods, NP-completeness, and advanced techniques. It supports undergraduate, graduate, and research-level study.

Recommended

Algorithm Design

Jon Kleinberg and Éva Tardos

1st edition, 2005

Kleinberg and Tardos teach divide-and-conquer, greedy methods, dynamic programming, network flows, NP-completeness, and approximation through examples and proofs. The text emphasizes how to recognize and construct effective algorithmic strategies.

Recommended

Data Structures and Algorithm Analysis in C++

Mark Allen Weiss

4th edition, 2014

Weiss combines classical data structures, rigorous algorithm analysis, and practical C++ implementations. It is well suited to advanced undergraduate study and to developing efficient problem-solving skills.

Recommended

Theory of Computation

Introduction to the Theory of Computation

Michael Sipser

3rd edition, 2012

Sipser introduces automata, formal languages, computability, undecidability, and computational complexity with clarity and mathematical rigor. It is a standard introductory theoretical-computer-science text.

Recommended

Introduction to Automata Theory, Languages, and Computation

John E. Hopcroft, Rajeev Motwani, and Jeffrey D. Ullman

3rd edition, 2006

This classic develops finite automata, regular and context-free languages, Turing machines, computability, and complexity through rigorous proofs and examples. It remains widely used in computer-science curricula.

Recommended

Elements of the Theory of Computation

Harry R. Lewis and Christos H. Papadimitriou

2nd edition, 1997

Lewis and Papadimitriou present automata, computability, formal languages, recursive functions, and complexity with mathematical precision. The book bridges undergraduate foundations and graduate theoretical computer science.

Recommended

Computational Complexity

Computational Complexity: A Modern Approach

Sanjeev Arora and Boaz Barak

1st edition, 2009

This graduate text develops complexity classes, reductions, randomness, approximation, interactive proofs, pseudorandomness, and quantum computation. It is a principal reference for modern computational-complexity research.

Recommended

Computational Complexity

Christos H. Papadimitriou

1st edition, 1994

Papadimitriou develops complexity through reductions, completeness, parallel computation, probabilistic computation, and optimization problems. It remains an influential theoretical-computer-science reference.

Recommended

Complexity and Real Computation

Lenore Blum, Felipe Cucker, Michael Shub, and Steve Smale

1st edition, 1998

This advanced monograph extends computational complexity from discrete models to continuous mathematics and numerical computation. It explores the research interface between mathematics, numerical analysis, and theoretical computer science.

Recommended

Computer Systems

Computer Organization and Design RISC-V Edition

David A. Patterson and John L. Hennessy

2nd edition, 2021

Patterson and Hennessy explain instruction sets, processor architecture, memory hierarchy, pipelining, parallelism, storage, and input/output using RISC-V. The text links hardware design with software execution.

Recommended

Computer Architecture: A Quantitative Approach

John L. Hennessy and David A. Patterson

6th edition, 2017

This authoritative graduate text analyzes processors, parallelism, memory, storage, interconnection networks, and performance using quantitative methods. It is a standard reference for advanced computer-architecture research.

Recommended

Structured Computer Organization

Andrew S. Tanenbaum and Todd Austin

6th edition, 2012

This book explains computers through abstraction levels from digital logic and microarchitecture to operating systems and programming languages. Its layered approach shows how complete computing systems are constructed.

Recommended

Operating Systems

Operating System Concepts

Abraham Silberschatz, Peter B. Galvin, and Greg Gagne

10th edition, 2018

The Dinosaur Book develops processes, threads, scheduling, memory, file systems, security, virtualization, and distributed systems. It remains one of the most widely adopted operating-systems texts.

Recommended

Modern Operating Systems

Andrew S. Tanenbaum and Herbert Bos

5th edition, 2022

Tanenbaum and Bos combine theory with implementation across processes, concurrency, memory, storage, security, virtualization, and mobile systems. It is valuable for both coursework and systems research.

Recommended

Operating Systems: Three Easy Pieces

Remzi H. Arpaci-Dusseau and Andrea C. Arpaci-Dusseau

1st edition, 2018

This free university text explains virtualization, concurrency, persistence, scheduling, synchronization, and storage through practical examples. It works especially well alongside a more formal operating-systems reference.

Recommended

Computer Networks

Computer Networking: A Top-Down Approach

James F. Kurose and Keith W. Ross

8th edition, 2021

Kurose and Ross explain networking from applications downward through transport, routing, congestion, wireless systems, multimedia, security, and Internet architecture. The balance of theory and protocols makes it a leading undergraduate text.

Recommended

Computer Networks

Andrew S. Tanenbaum and David J. Wetherall

5th edition, 2011

This classic develops network architectures, routing, transport protocols, wireless communication, security, and Internet technologies from a systems perspective. It supports both education and professional reference.

Recommended

Data and Computer Communications

William Stallings

11th edition, 2022

Stallings covers data communications, network architectures, switching, routing, wireless networks, security, congestion control, and Internet protocols. It bridges communication engineering and computer networking.

Recommended

Databases

Database System Concepts

Abraham Silberschatz, Henry F. Korth, and S. Sudarshan

7th edition, 2019

This standard text develops relational databases, SQL, indexing, query optimization, transactions, concurrency, recovery, distributed databases, and modern data-management systems. It supports undergraduate and graduate database courses.

Recommended

Fundamentals of Database Systems

Ramez Elmasri and Shamkant B. Navathe

7th edition, 2016

Elmasri and Navathe present conceptual modeling, relational databases, SQL, normalization, transactions, distributed and object-oriented databases, and warehousing. The text connects theory with practical database design.

Recommended

Readings in Database Systems

Peter Bailis, Joseph M. Hellerstein, and Michael Stonebraker

5th edition, 2015

The Red Book combines influential database research papers with editorial commentary on transactions, query processing, distributed data, analytics, and modern architectures. This free collection is particularly valuable to graduate students and researchers.

Recommended

Software Engineering

Software Engineering

Ian Sommerville

10th edition, 2015

Sommerville develops software processes, requirements, architecture, design, verification, project management, security, agile methods, and dependable systems. It is one of the most widely used university software-engineering texts.

Recommended

Software Engineering: A Practitioner's Approach

Roger S. Pressman and Bruce R. Maxim

9th edition, 2019

Pressman and Maxim combine engineering principles with software processes, design, testing, quality assurance, DevOps, maintenance, and project management. It is widely adopted in professional software-engineering education.

Recommended

The Mythical Man-Month: Essays on Software Engineering

Frederick P. Brooks Jr.

Anniversary edition, 1995

Brooks examines software project management, complexity, scheduling, architecture, communication, and the human side of development. The essays remain influential for large-scale engineering and project leadership.

Recommended
