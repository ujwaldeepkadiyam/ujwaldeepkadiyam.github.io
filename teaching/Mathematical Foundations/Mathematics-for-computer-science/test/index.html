You can write normal text in paragraphs. Math works with inline notation like \(a \in \mathbb{Z}_n\) and display math:

\[a + b \equiv c \pmod{n}.\]

Example: Homomorphism \(\phi : \mathbb{Z} \to \mathbb{Z}_n\)

Define \[\phi(a) = a \bmod n.\]

Then \[\phi(a+b) = \phi(a) + \phi(b)\] so \(\phi\) is a group homomorphism from \((\mathbb{Z},+)\) to \((\mathbb{Z}_n,+)\).
