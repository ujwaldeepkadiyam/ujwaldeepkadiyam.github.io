A short course on how Git works under the hood — not just the commands, but the model behind them: commits as snapshots, branches as movable pointers, and HEAD as the thing that tracks where you currently are.

1. [Introduction to Git Commits](/learning/git/introduction-to-git-commits/) — what a commit is, why they're lightweight, and how `main` is just a movable label.
2. [Git Branches](/learning/git/git-branches/) — creating and switching branches, working on them independently, merging, and how HEAD tracks your current branch.

More lessons will be added here as the course grows.
